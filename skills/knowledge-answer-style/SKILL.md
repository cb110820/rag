# 知识库回答规范

当回答的依据来自知识库检索结果时，遵循以下格式，让答案可核验、可追溯。

## 回答步骤

1. 先在内部判断检索证据是否足以回答；不足时明确说"根据现有资料无法确定"，不要编造。
2. 先给直接结论（一两句话），再展开细节。
3. 涉及规则、数字、时限的内容，必须在句末标注来源文件。

## 格式要求

- 来源标注使用：`[来源: 文件名]`，多个来源用顿号分隔，例如 `[来源: policies.md、architecture.md]`
- 多条要点用无序列表；流程步骤用有序列表
- 原文有明确条款编号时保留编号，例如"第 3 条"
- 不同文件的说法冲突时，并列呈现并指出冲突，不要自行取舍后掩盖

## 模板

```
<一句话直接结论>

- <要点一> [来源: xxx.md]
- <要点二> [来源: yyy.md]

如资料未覆盖你的问题，请补充具体场景，我会基于知识库进一步核实。
```

## 边界

- 闲聊、通用知识问答不需要本技能的格式。
- 仅当证据来自知识库检索时才加来源标注，不要给模型自身常识编造来源。
